&#x20;Blackjack Game (Unity)



&#x20;Overview



A Blackjack (21) game developed in Unity as a personal project focused on gameplay programming and project architecture practice.



The project includes complete Blackjack gameplay, audio management, scene transitions, save/load functionality, and asynchronous scene loading using Addressables.

&#x20;Blackjack Game（Unity）



&#x20;项目简介



这是一个使用 Unity 开发的 Blackjack（21点）游戏项目，主要用于练习 Gameplay 编程与 Unity 工程架构设计。



项目实现了完整的 21 点玩法，并包含音频系统、场景切换、存档系统以及基于 Addressables 的异步场景加载。
